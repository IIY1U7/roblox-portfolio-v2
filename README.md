# Roblox Portfolio

Page de portfolio Roblox rétro, prête pour GitHub Pages.

## Personnalisation rapide

La page contient uniquement la navigation demandée, le logo Roblox et l'emplacement de l'avatar. Pour mettre votre vrai avatar, suivez le commentaire placé dans `index.html`.

## Publication sur GitHub Pages

1. Créez un nouveau dépôt GitHub.
2. Ajoutez `index.html`, `styles.css`, `script.js` et votre éventuel dossier `assets` à la racine du dépôt.
3. Dans **Settings → Pages**, choisissez **Deploy from a branch**, puis la branche `main` et le dossier `/ (root)`.

Le site ne nécessite aucune installation ni compilation.
